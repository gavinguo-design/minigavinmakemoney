# A/B/C 情景权重两年回测报告（v1 vs v2.1）

> 只评估，未调任何系数。生成：`node scripts/backtest-weights.cjs`；代码基线 620552f（main，含 v2.1 修复）。

## 1. 数据与方法
- 行情：yahoo-finance-v8-chart，`research/backtest/data/hsi-daily-2024-06_2026-10.json`，2024-06-03 起（预热 4 个月），candles sha256 `9d743b690c800ae1b0b55f56abbc9004a4f3047a5f07ace4a3fe805fe8a60fa9`，原始响应 sha256 `2361b360c767c9c84c1aa9ba973903878697baffba5fab6358135504827407a3`。与仓库 `kline_futu.json` 重叠 129 个交易日（2026-04-02~10-09）OHLC 最大差 0。
- 评估窗口：2024-10-02 ~ 2026-10-09，**498 个交易日**，跳过 0 天。
- 每个交易日 t：只用 t 之前已完成日 K，`require` 调用 `daily-analysis.cjs` 的 `build({backfill:true, ruleWeights:true})` 生成 A/B/C price_rule，再用同一输入分别以 `scoreScenarioWeights({model:WEIGHT_MODEL_V1})` 和 `({model:WEIGHT_MODEL_V2})`（rule-weights-v2.1）打分；t 日收盘用 `MarketRules.priceCondition` 对同一组 price_rule 判定实际情景（三分区恰好一个成立）。
- 防未来函数：`tests/backtest-weights.cjs` 断言打乱+放大、或删除 t 及以后的 K 线，t 的规则与两套权重完全不变；延长回测终点不改变早期行。
- 基准：均匀 1/3；历史频率（只用 t 之前已实现结果，+1 平滑）；持续（t-1 成立情景 0.6，其余各 0.2）。
- 宽度/南向：unavailable (no point-in-time history in repo); breadth factor = 0 for all models；南向：research/data/ 在运行时不存在（另一任务尚未推送），**带宽度因子的对照版跳过**，未自造数据。
- Brier 为三类求和形式（0–2，均匀=0.667）；CI 为 10 日移动块 bootstrap 2000 次。
- 实际情景分布：A 0.2711 / B 0.5683 / C 0.1606。

## 7. 结论
1. v1 显著优于均匀、历史频率和持续基准（对持续差值 CI 不含 0，但优势仅 0.03）。
2. **v2.1 显著劣于 v1**（Brier +0.078，CI [0.038, 0.120]），且劣于持续基准；在前 70% / 后 30%、各年份、两种 regime 下均未胜过 v1。**不建议把生产默认切到 v2.1**。
3. 最大问题：81%（405/498）的交易日实际情景就是 t-1 收盘所在分区，任务本质接近"持续性"，模型的增量信息很少；v2.1 的区间门控在 range 下系统性高估 B：188 天 t-1 收盘已在 [lower,upper) 之外，其中 74 天 v2.1 仍判为 range 并加权 B，而这 74 天有 61 天（82%）当日仍收在突破一侧——摆动点 HH/HL 需要确认枢轴，滞后于突破，门控与"已突破"状态冲突。
4. 本次未调参；任何系数修改需另立研究卡并做样本外验证。

## 8. 宽度/南向对照（v1 + 市场宽度 / 南向资金）

> 只评估，不改生产代码与系数。生成：`node scripts/backtest-breadth-southbound.cjs`；代码基线 6ba306e。明细 `daily-ledger-breadth-southbound.csv`，结果 `results-v1-breadth.json` / `results-v1-southbound.json` / `results-v1-both.json` / `results-v1-cap085.json`。

### 8.1 数据与防未来
- 宽度：`research/data/hsi-breadth-daily.json`（point-in-time 成分，等权收盘对收盘，非加权）；南向：`research/data/southbound-daily.json`（东方财富 total_net，亿港元；24 天南向休市）。
- t 日只用 **date < t** 的最近一行：宽度取 t-1 交易日；南向取 t 之前最近一个南向开市日，若 t-1 南向休市则沿用更早开市日并标注 stale（20 天）。`tests/backtest-breadth-southbound.cjs` 断言删除/篡改 t 及以后的宽度、南向数据不改变 t 的信号与概率。
- 宽度首日（2024-10-02，前一交易日 2024-09-30 不在数据内）不可用 1 天；南向 z-score 需要 60 个此前开市日，前 65 天信号为 0（不可用），故南向实际生效 433 天。
- v1 logits 由回测脚本按 `scoreScenarioWeights` v1 分支逐项复现（未取整），498 天经同一 `boundedRound` 后与生产 v1 概率逐日完全一致（脚本内断言）。

### 8.2 对照定义（事先定死，未看结果调参）
- 生产 v1 的 breadth 因子依赖 `MP.signal(participation)`：等权宽度 0.45 + **加权宽度** 0.35 + **点数贡献方向** 0.20，并按**前五贡献集中度**打折。历史宽度数据只有等权涨跌家数与 MA20 上方占比，缺加权宽度/贡献/集中度，**无法映射成同口径**，因此用独立定义：
  - 宽度信号 b = clip(0.5·(2·adv_ratio−1) + 0.5·(2·pct_above_ma20−1), −1, 1)，系数 0.4（= WEIGHT_MODEL_V1.coefficients.breadth）；
  - 南向信号 s = clip(z, −2, 2)/2，z = (total_net_{最近开市日} − 前 60 个开市日均值)/样本标准差，系数 0.3；
  - 与 v1 的 breadth 项同方式进入 logits：A += 系数·信号，C −= 系数·信号，B 不变；再 softmax + 生产 `boundedRound`（[0.10,0.70]，步长 0.05）。

### 8.9 结论
1. v1+breadth：Brier 差 0.0092 [0.0041, 0.0145]，前70% 0.0073 / 后30% 0.0136；**显著更差**。
2. v1+southbound：Brier 差 0.0034 [-0.0012, 0.0078]，前70% 0.0026 / 后30% 0.0051；与 v1 无显著差异。
3. v1+both：Brier 差 0.0107 [0.0048, 0.0169]，前70% 0.0093 / 后30% 0.0139；**显著更差**。
4. 单因子信息量：宽度对 t 日收益 corr -0.0676 [-0.1619, 0.0163]、方向命中 0.4767；南向 corr -0.0689 [-0.1689, 0.0523]、方向命中 0.4573——均无可用的次日方向信息（点估计略偏反向）。宽度与 A/B/C 方向的 corr 0.5698 主要来自 t-1 收盘位置（宽度信号与 v1 的 A−C 倾向 corr 0.6999，已在 position/trend 项中），属共线而非增量信息。
5. 上限放宽到 0.85（敏感性，不采纳）：v1 0.0033 [0.0004, 0.006]，前70% 0.004 / 后30% 0.0019；v1+两者 0.0096 [0.0039, 0.0151]，前70% 0.0092 / 后30% 0.0107。上限 0.85 **从未被触及**：v1 softmax 原始最大概率仅 0.7637（logit 量级本身偏小），再经下限 0.10 重分配后最大仍为 0.70；放宽上限后，63 天原本被截在 0.70 的主情景改由下限 0.10 重分配（约 0.68–0.69）并按 0.05 步长向下取整为 0.65，反而更保守，故略差。v1 的保守来自 logit 尺度 + 0.10 下限，而非 0.70 上限（低档预测 ~0.11 实际 <1%）。
6. 生产建议：宽度/南向两版均**不建议并入生产**（未显著优于 v1 或前后不一致）；上限调整需另立研究卡并做样本外验证，本次不改生产。
