# 预注册：尼森蜡烛图反转形态在 A/C 边界处的「拒回」效应（恒指日线）

- 登记时间：2026-10-12 HKT（看任何事件统计结果之前提交）
- 分支：`research/candle-boundary`（从 origin/main 13d9250 切出）。纯研究，不接生产。
- 已知信息声明：登记前只看过数据结构和两个计数（总共 3050 个 session；收盘距上边界 ≤0.5×ATR 的有 474 天，距下边界的有 413 天）。这两个计数没有按形态拆分，也没有看任何结果变量。

## 1. 数据与时点
- K 线：`research/v4/data/HSI.json`（Yahoo ^HSI 日线，2014-01-02 ~ 2026-10-09，已与富途快照对账）。
- 剧本：`research/v4/data/sessions.json`（`scripts/v4-generate.cjs` 用生产 `DA.build()` 重放，3050 个 session，2014-03-31 ~ 2026-10-09）。每个 session t 的 `upper`（A 上边界）、`lower`（C 下边界）、`atr14`、`base_close` 都只用基准日 b（t 之前最后一个交易日）及以前的 K 线算出，是当天冻结的剧本值。
- 形态：`investment/chart/patterns.js` 的 `detect()`，参数为生产默认 CFG，不改任何阈值。**严格按时点计算**：对基准日 b，只把 b 及以前的 K 线传进 `detect(bars[0..b])`，取 index=b 的形态（包括以 b 收尾的双根、三根组合）。每根 K 线最多保留一个形态，按生产 PRIORITY 去重，这一点照搬不改。

## 2. 事件定义（主分析 k = 0.5）
- **上边界附近**：|base_close − upper| ≤ k × atr14（收在边界上方或下方都算）。
- **下边界附近**：|base_close − lower| ≤ k × atr14。
- **看跌反转形态集合**（在上边界检验）：`bearEngulf` 看跌吞没、`darkCloud` 乌云盖顶、`eveningStar` 黄昏之星、`shootingStar` 射击之星、`hangingMan` 上吊线、`doji` 十字星。
- **看涨反转形态集合**（在下边界检验）：`bullEngulf` 看涨吞没、`piercing` 曙光初现（刺透）、`morningStar` 早晨之星、`hammer` 锤子线、`invHammer` 倒锤子、`doji` 十字星。
- 不算反转形态：`threeSoldiers`、`threeCrows`、`maruBull`、`maruBear`、`gapUp`、`gapDown`（这些是趋势或动能形态）。
- **事件组**：靠近该边界，且基准日 K 线带有对应方向的反转形态。
- **对照组**：靠近该边界，但基准日 K 线没有对应方向的反转形态（可以带其他形态，也可以什么形态都没有）。
- 如果某天同时靠近上下两条边界（区间窄于 2k×ATR），两侧分析各计一次。
- 敏感性：k = 0.25、1.0 只做附表，**主结论只用 k = 0.5**。

## 3. 结果变量
- **主指标 R1（次日拒回）**：上边界情形 = session t 收盘 < upper（即结局不是 A）；下边界情形 = t 收盘 ≥ lower（即结局不是 C）。这和生产 `priceCondition` 的判定一致。
- 次指标 R3（3 日拒回）：t、t+1、t+2 三个收盘全部没有越过 t 当天冻结的边界（上边界：都 < upper；下边界：都 ≥ lower）。HSI 数据里没有 t+2 的样本剔除。
- 次指标 RET：(close_t − base_close)/atr14，并把方向翻成「反转方向为正」（上边界取负号，下边界原样）。
- 关于 R1 的说明：形态本身会影响收盘相对边界的位置（例如看跌吞没收盘通常已经压到边界下方），所以 R1 的差异可能只是「位置效应」。为此另做次分析 **ADJ**：logistic 回归 R1 ~ 形态指示 + 有符号距离 (base_close − 边界)/atr14，报告形态系数的 95% CI（Wald）。

## 4. 检验
- **主检验（只有两项）**：①「全部看跌反转合并 @ 上边界」与 ②「全部看涨反转合并 @ 下边界」两组的 R1 比例差（事件 − 对照），用 Newcombe 混合 score 95% CI（Wilson 基础），并给 Fisher 精确双侧 p 值。两项做 Holm 校正，α = 0.05。另外报告按日历年分块 bootstrap（4000 次）的差值 CI，作为稳健性检查（事件日可能聚集）。
- **判定标准（预先写定）**：
  - **有效**：主检验的 Newcombe CI 下限 > 0，Holm 校正后 p < 0.05，**并且** ADJ 中形态系数 CI 不跨 0（方向是增加拒回），**并且** v4 增量检验通过（见下）。
  - **部分有效**：比例差显著，但 ADJ 或 v4 增量不显著。这说明形态的信息已经被「收盘位置」或 v4 吸收，对生产没有增量。
  - **无效**：比例差 CI 跨 0，或方向相反。
  - **样本不足**：事件组 n < 30 时直说「样本不足无法判断」，不下结论。
- **逐年**：2014 ~ 2026 每年分别列出两组的 n 和 R1。统计事件组拒回率高于对照组的年份数（只算事件组 n ≥ 3 的年份）。
- **单形态拆分**：上边界 6 个、下边界 6 个，共 12 个检验（Fisher 精确双侧，各形态 vs 同一对照组）。对这 12 个 p 值同时报告 Holm 和 BH（FDR 5%）校正结果。单形态结果只作描述，**不作为主结论**。
- **对 v4 的增量**（walk-forward，复用 `scripts/v4-walkforward.py` 的协议：评估 2016 ~ 2025，评估年 Y 只用 date < Y 的数据训练，λ 在训练窗内选，输出经过生产 boundedRound）：
  - 基线 = v4 冻结特征集 `v3+overnight+struct+imp`，按同一流程重训。
  - 候选 = 基线 + 两个特征：`bear_rev_at_upper`（靠近上边界 k=0.5 且基准日有看跌反转形态，取 0/1）、`bull_rev_at_lower`（镜像）。
  - 在全部 session 上训练，**只在边界日（靠近上或下边界，k=0.5）上**比较 Brier（三类求和）。报告 ΔBrier（候选 − 基线）、按年分块 bootstrap 95% CI、胜出年数。另外报告只在事件日上的 ΔBrier（描述用）。
  - 通过标准：ΔBrier 的年块 CI 上限 < 0，且至少 7/10 年胜出。
  - 唯一的次变体（台账记录，但不用于结论）：候选特征换成「不限位置」的 `bear_rev`、`bull_rev` 指示。
- 2026 年数据会纳入比例检验，因为它不涉及模型选择。v4 增量检验 2026 只作参考，不计入结论。
