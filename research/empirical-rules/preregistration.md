# 经验规则研究 · 预注册（看结果前提交）

日期：2026-10-12 HKT。分支 `research/empirical-rules`（源自 origin/main f474b1e）。只做研究，不改生产。

## 0. 数据
- 会话：`research/v4/data/sessions.json`（scripts/v4-generate.cjs 用生产 build() 重放，3050 天，2014-03-31 ~ 2026-10-09）。每天有 lower/upper（C/A 边界）、base_close（前一完成交易日收盘）、atr14、adx14、prev_zone（生产 v3 的 previousZone）、outcome（当日收盘按 price_rule 判 A/B/C）。
- 盘前特征：`research/v4/data/features.json`（scripts/v4-features.py，时点规则见其头注释：只用 08:45 HKT 前已收盘的美股/ETF 日线）。
- 前日跳空：用 `research/v4/data/HSI.json`，基准日 b 的开盘 vs b 前一根收盘（全部 ≤ b，盘前已知）。
- 模型预测：`research/v4/predictions.csv` 中 `v3+overnight+struct+imp`（= 生产 v4 结构的逐年 walk-forward 样本外预测，2016 起）。

## 1. 样本切分（固定，不再改动）
- 发现期 D：2014-03-31 ~ 2021-12-31（"模型可信度"规则因模型预测 2016 起，D = 2016 ~ 2021）。
- 样本外 O：2022-01-01 ~ 2025-12-31，**只跑一次**。
- 额外观察 X：2026-01-01 至今，仅展示，不参与判定。

## 2. 结局
- H1（次日）：会话 t 收盘落在 t 的 A/B/C（= sessions.outcome）。
- H3（次 3 日）：会话 t 起第 3 个交易日（t+2，按 HSI 实际交易日）收盘，按 **会话 t 的同一组 A/B/C 线** 判区（A: ≥upper；C: <lower；B: 其间）。尾部不足 3 天的会话丢弃。

## 3. 候选条件维度（共 9 个，阈值固定）
| 代号 | 含义 | 档位 |
|---|---|---|
| PZ | 前日收在哪区（生产 prev_zone） | A / B / C |
| POS | 前收相对**今日**线的位置 | 已在C区(<lower) / B下1/3 / B中1/3 / B上1/3 / 已在A区(≥upper) |
| EDGE | 前收距"所在区边界"的 ATR 距离（A区: base−upper；C区: lower−base；B区: 距较近一条线） | <0.3 / 0.3~1 / ≥1 |
| FXI | 隔夜 FXI 变动（log ret） | <−1% / −1%~+1% / >+1% |
| KWEB | 隔夜 KWEB 变动 | 同上 |
| EWH | 隔夜 EWH 变动 | 同上 |
| WID | 区间宽度 (upper−lower)/ATR | <2 / 2~3.5 / ≥3.5 |
| GAP | 前日跳空 (open_b − close_{b−1})/ATR | 下跳 <−0.3 / 无 / 上跳 >+0.3 |
| ADX | ADX14 | <20 / 20~25 / ≥25 |

只允许单条件（9 维全部档位）或两条件组合（36 个维度对的全部档位交叉）。每个格子 × 两个结局 H1/H3 都写入 `search-ledger.json`，无论好坏。

## 4. 基线
- 无条件基线：同期全部会话的 A/B/C 比例。
- 「前日区持续」基线：按格子内样本的 PZ 构成加权的同期 P(结局 | PZ)。即"只知道前日在哪区"时应期望的比例。规则的价值 = 相对这个基线的偏离。

## 5. 发现期筛选（D 上）
对每个格子、每个结局类 k∈{A,B,C}：Δ_k = 格子比例 − 持续基线期望。取 |Δ| 最大的类为该格子的"信号类"。
入选候选：n_D ≥ 40，|Δ| ≥ 10 个百分点，且二项检验（对持续基线期望）双侧 p < 0.01。

## 6. 样本外判定（O 上，只跑一次）
候选规则在 O 上"成立"= 同时满足：
1. n_O ≥ 30；
2. Δ_O 与 Δ_D 同号，且 |Δ_O| ≥ 5 个百分点；
3. 信号类比例的 Wilson 95% CI 宽度 ≤ 35 个百分点。
另标"强"：O 上 Wilson 95% CI 不含持续基线期望。
不满足的列为"被样本外推翻/未确认"，单独列出。

## 7. "别信模型 / 少做"规则
- 模型：v4 结构的 walk-forward 样本外预测，取概率最高的情景为"首选"。
- 对同样的格子（单条件 + 两条件），在 D(2016~2021) 计算首选命中率与 Brier。候选：n_D ≥ 40 且首选命中率比 D 全样本低 ≥ 10 个百分点（二项 p<0.01），或格子内三类最大比例 ≤ 50%（近均匀）且 n_D ≥ 40。
- O 上成立：n_O ≥ 30，命中率仍低于 O 全样本 ≥ 5 个百分点（或最大比例仍 ≤ 55%）。

## 8. 速查表选取（预先规定，避免挑樱桃）
从 O 上成立的规则中：两条件规则仅当它在 D 上的 |Δ| 比其两个父单条件规则都大 ≥ 5 个百分点时保留；然后按 D 上 z 值降序，同一维度对最多 2 条，最多 10 条。

## 9. 已知局限（事先承认）
- 日度结局自相关（区持续），H3 格子之间重叠，Wilson CI 偏窄。
- 维度和阈值是根据业务直觉与特征分布（不看结局）预设的；发现期多重比较由 p<0.01 + 样本外一次检验控制，但不是严格的 FDR。
