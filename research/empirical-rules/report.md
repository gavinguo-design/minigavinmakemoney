# 恒指 A/B/C 经验规则（回测样本总结）

> 2026-10-12 HKT。分支 `research/empirical-rules`。**只是研究，没有改生产。**
> 复现：`python3 scripts/empirical-rules.py`。输出：`search-ledger.json`（全部尝试）、`results.json`（全部数字）、`tables.md`（全部表格）。
> 预注册：`preregistration.md`。它在看结果之前单独提交（commit e250d8b）。

## 一句话结论
真正最有用的信息只有一条：**前一天收在哪个区，第二天大概率还在那个区**（约 75%~81%）。在这条基础上，有几种情况能稳定地把概率再往上或往下推 10~30 个百分点。这些情况在 2022~2025 年的新数据上也成立。
相反，**隔夜美股（FXI/KWEB/EWH）、ADX、前日跳空单独看几乎没用**，它们只有跟"位置"一起看才有一点作用。

## 怎么做的（通俗版）
- 样本：3050 个交易日（2014-03~2026-10）。每天都用生产程序重放当天的 A/B/C 两条线，再看当天收盘落在哪个区。
- 先在**2014~2021 年**（1881 天）里找规律。然后把找到的规律**只拿一次**去 **2022~2025 年**（979 天，找规律时没看过）检验。2026 年至今（190 天）只作为额外观察。
- 条件只用 9 种开盘前就知道的信息，阈值事先固定：前日区、前收在今天两条线之间的位置、离最近一条线有几个 ATR、隔夜 FXI/KWEB/EWH 涨跌、区间宽度、前日跳空、ADX。只允许单个条件或两个条件组合，一共 401 个格子 × 2 种结局（次日 / 第 3 日）= 802 次尝试，全部记在 ledger 里。
- "第 3 日"的意思是：从当天算起第 3 个交易日的收盘，仍然按**当天那两条线**判 A/B/C。
- 比较基准有两个：
  - "无条件比例"：完全不看任何信息时的比例。
  - "持续基线"：只知道前一天在哪个区时应该期待的比例。规则的价值看它**比持续基线多出了多少**。
- 一条规则在样本外算"成立"，要同时满足 4 点：样本外 n≥30；方向和发现期相同；偏离持续基线至少 5 个百分点；95% 区间宽度不超过 35 个百分点。
- 结果：802 次尝试中，发现期有 213 条入选候选（含次日/第 3 日），样本外成立 191 条，其中 157 条样本外 95% 区间完全不含基线。候选成立率高，主要是因为这些规则大多是同一个现象（"位置"）的不同切法，彼此高度重叠，不是 191 个独立发现。

## 可靠的规则（样本外仍成立）

术语：
- "B 区上 1/3"指前收在今天 C 线和 A 线之间、靠上的三分之一。
- "贴线"指前收离最近一条线不到 0.3 个 ATR。
- "远离线"指距离 ≥1 个 ATR。
- "区间宽"指两条线相距 ≥3.5 个 ATR，"区间窄"指相距 <2 个 ATR。

1. **区间宽（≥3.5 ATR）→ 基本就在 B 区里磨。** 次日收 B：79%（发现期 n=500）→ 88%（样本外 n=235），持续基线 61%/68%。第 3 日收 B：70% → 79%。如果前收还在 B 区中间 1/3，第 3 日收 B 是 93%（n=167）→ 89%（n=117）。
2. **区间窄（<2 ATR）→ 第二天很可能换区。** 次日收 B 只有 30%（n=617）→ 28%（n=349），A/B/C 接近三等分（发现期 40/30/30，样本外 31/28/41）。前日在 B 时，第 3 日仍在 B 只有 40%（n=216）→ 44%（n=113），持续基线约 64%。
3. **前日在 B，前收在 B 区下 1/3 → 次日掉进 C 的概率是平常的 2.5~3 倍。** 次日收 C：24%（n=272）→ 29%（n=139），持续基线约 10%。如果隔夜 FXI 跌超 1%，次日收 C 为 32%（n=78）→ 43%（n=61）；第 3 日收 C 为 44% → 54%。
4. **前日在 B，前收在 B 区上 1/3 → 次日冲上 A 的概率翻倍。** 次日收 A：23%（n=324）→ 22%（n=145），持续基线约 10%。如果隔夜 FXI 涨超 1%，次日收 A 为 33%（n=95）→ 43%（n=47）。
5. **前日在 B 但贴着某条线（<0.3 ATR）→ "还在 B"只比一半多一点。** 次日收 B：57%（n=176）→ 55%（n=80），持续基线 81%。只看 B 区上 1/3 并贴着 A 线的情况，次日收 A 为 40%（n=114）→ 34%（n=41），样本外区间 22%~49%，偏宽。
6. **已经在 A 区（或 C 区）并且远离线 ≥1 ATR → 次日几乎一定还在原区。** A 的情况：100%（n=250）→ 97%（n=98）。C 的情况：97%（n=155）→ 98%（n=99）。第 3 日也有 94%/91%（A）和 90%/91%（C）。
7. **在 A 区但贴着 A 线 → 第 3 日只有一半还留在 A。** 第 3 日收 A：56%（n=77）→ 50%（n=46），持续基线约 77%/72%。次日回落 B 的比例为 34% → 48%。

## 什么时候别信模型 / 该少做（样本外验证）
"模型"指 v4 结构（生产现用）的逐年 walk-forward 样本外预测，取概率最高的情景作为"首选"。
- 全样本首选命中：发现期 84%（n=1455，2016~2021），样本外 84%（n=979），2026 年 82%（n=190）。

**少做规则：**
- **A. 前收贴线（<0.3 ATR，无论哪个区）→ 模型首选只对六成左右。** 首选命中：62%（n=242）→ 64%（n=173），整体是 84%。这类日子的反转率为 45%/42%（整体 21%），结局最大比例不到 50%（A/B/C 样本外 22/47/31%），**接近抛硬币**。2026 年这一组命中 71%（n=38），好一些，但样本小。
- **B. 区间窄（<2 ATR）→ 模型命中不受影响（79%/79%），但结局本身接近三等分。** 意思是"模型能猜到在哪个区，但区间太窄、来回穿越，按区做的盈亏比差"。前日在 B 且区间窄时，首选命中 59%（n=172）→ 63%（n=113）。
- **C. 最差组合：前日在 B 且贴线，或前收在 B 区上 1/3 且贴 A 线 → 首选命中只有 55%/54%（发现期），样本外 64%/59%（n=80/41）。** 这时候应该降仓，或等盘中确认后再动。
- 反面（**可以多信模型**）：前收离线 ≥1 ATR 时，首选命中 97%（n=658）→ 97%（n=429），2026 年 96%（n=73）。

## 被样本外推翻或未确认的规则（诚实列出）
发现期候选 213 条，其中 22 条没过样本外。最值得记住的几条：
- **"贴线 + 隔夜 FXI/KWEB 大涨 >1% → 次日上 A"：被推翻，方向反了。**
  - 发现期：次日收 A 为 55%（n=88）/ 49%（n=103），高于基线 32%/29%。
  - 样本外：只有 37%（n=46）/ 38%（n=50），**低于**基线 40%/41%。
  - 也就是说，2022 年后隔夜美股大涨并不能帮恒指冲线。
- **"前日在 A 但前收已跌回 B 区上 1/3 → 次日很难再回 A"：样本太少（n=17），无法确认。** 发现期次日回 A 只有 6%（n=54），样本外是 35%。
- **"前日在 A/C + 区间宽 → 次日回 B"：样本外 n=24~26，不够 30，未确认。** 方向一致：前日在 C 时次日回 B 为 55% → 75%。
- **"B 区上 1/3 + 前日向上跳空 → 第 3 日上 A"：样本外几乎没有优势。** 38% → 23%（n=48），基线 24%/21%。
- 其余未过的条目都是 n<30 或偏离不足 5 个百分点，完整列表见 `tables.md`。
- **单独的隔夜 FXI/KWEB/EWH、ADX、前日跳空：在发现期就没有一个单条件过筛（偏离 <10 个百分点）。** 它们只在和"位置"组合时才起作用。

## 局限（请认真看）
1. **这些规则高度重叠。** 本质上只有三个现象：①前收在区间里的位置/离线多远；②区间宽窄；③前日在哪区。191 条"成立"不等于 191 个独立证据。
2. **结局有自相关**（区会连续几天持续），"第 3 日"的样本还相互重叠，所以 95% 区间**偏乐观**（偏窄）。
3. **样本外比例不少偏离得比发现期还大**（例如规则 1、3）。这说明 2022~2025 年的市场比 2014~2021 年更"区间化"。ATR 中位数 358 → 381，变化不大，但宽区间更常见，所以规律未必年年一样。
4. 规则 5 的子情况、少做规则 C 的样本外 n 只有 41，区间宽 25~27 个百分点，只能算"方向可信，幅度不精确"。
5. **预注册的"近均匀"判据有缺陷。** 它把不同前日区的日子混在一起算比例，所以"离线 ≥1 ATR"也被标成了"近均匀"，而模型在这类日子其实命中 97%。这一条在速查表里按"命中率"解读，不按"近均匀"解读。所有 103 个可信度候选的完整结果见 `tables.md`。
6. 这些规则描述的是"收盘落在哪个区"，**不是收益率**。"该少做"是根据命中率和反转率推断的，没有用实际交易盈亏验证。
7. 2026 年只有 190 天，每条规则的 n 只有 13~45，只作参考。
