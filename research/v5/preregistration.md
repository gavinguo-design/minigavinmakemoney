# v5 预注册（在运行任何 v5 实验之前写入并提交）

时间：2026-10-12 HKT。基线 = v4 候选 `v3+overnight+struct+imp`（LR，λ 训练窗内选），框架完全沿用 `scripts/v4-walkforward.py`：
扩窗 walk-forward，评估年 2016..2025（n=2434），2026 只作参考；所有输出经生产 boundedRound[0.10,0.85] 步长 0.05；
指标：Brier（三类求和）、LogLoss、命中率、ECE（10 桶，同 v4-lib.ece）；CI：年块 bootstrap 4000 次（seed 20261012）。

## 已知事实（实验前诊断，仅看过 v4 自身已发表的 walk-forward 预测）
- v4 原始概率（未取整）ECE=0.011；取整到生产格式后 ECE=0.079。差异主要来自格式下限 0.10（该档 3858 个格子实际发生率 2.4%）
  和事实上限 0.80（[0.10,0.85] 且三项和=1 时最大只能 0.80；该档 1432 格实际 94.9%）。

## 方向 1：校准层（全部尝试）
校准器只在"训练折"上拟合：评估年 Y 的校准器，用 v4 在年份 < Y 的**样本外** walk-forward 预测拟合
（2015 年的样本外预测由仅用 2014 数据训练的 v4 得到；2016 的校准器只有 2015 一年数据）。
候选（固定清单）：
 C1 温度缩放（单个 T，作用于 log 概率，最小化 log loss）
 C2 向量缩放（每类一个缩放+偏置，最小化 log loss）
 C3 Platt（每类一对多 sigmoid(a·logit p + b)，再归一化）
 C4 Isotonic（每类一对多保序回归，再归一化，裁剪到 [1e-3,1-1e-3]）
 C5 温度缩放，但 T 以"取整后 Brier"为目标在训练折上网格搜索（格式感知）
判定规则：取整后 ECE 下降，且 ΔBrier(vs v4) 年块 CI 上界 < +0.001，且 LogLoss 不升 → 才推荐。多个通过时选取整后 Brier 最低者。
附加（仅信息，不作为 v5 候选，因为改格式是产品决策）：同样 v4 概率在 [0.05,0.90] 格式下的 ECE/Brier。

## 方向 2：港美脱钩（全部尝试，固定清单，D1..D6）
脱钩指标（全部只用基准日及以前的数据）：
 rho_spx_N = 最近 N 个已完成港股会话里，"该会话 HSI 收盘收益" 与 "该会话盘前 GSPC 隔夜变动(GSPC_ret)" 的相关系数（N=60 或 120）。
 rho_ewh_60 = 同上，用 EWH_ret。
 g_N = clip(rho_spx_N / 0.5, 0, 1)（脱钩时 → 0）。
 D1 v4 + rho_spx_60（水平项）
 D2 v4 + {GSPC_atr, IXIC_atr, VIX_chg} × rho_spx_60 交互项（保留原项）
 D3 v4，但 {GSPC_atr, IXIC_atr, VIX_chg} 替换为 ×g_60（脱钩时降权，任务要求的主方案）
 D4 同 D3，用 g_120
 D5 v4 + rho_ewh_60 + EWH_atr×rho_ewh_60 + imp_up/lo×rho_ewh_60
 D6 v4 + rho_spx_60 + 美股三项×rho_spx_60 + rho_ewh_60（D1+D2+rho_ewh 水平）
选择规则（看结果前声明）：在 D1..D6 中取 walk-forward 2016-2025 取整后 Brier 最低者；
它通过当且仅当：ΔBrier vs v4 年块 CI 上界 < 0 且 ≥6/10 年胜出 且 2017-2019 子集 Δ<0。
同时报告嵌套选择（每年只用之前年份成绩在 {v4, D1..D6} 中选）。保留集 = 2026-01-01..2026-10-09（190 天，只看一次，且按 v4 报告其后半段不完全干净）。
若无候选通过 → v5 不采用脱钩特征，如实报告。
